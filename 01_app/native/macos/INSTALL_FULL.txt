NERO 信披系统 1.0 · 完整试运行迁移版

适用于 macOS 13.5 或更新版本。安装器自动选择 M 系列或 Intel 组件。

1. 打开本 DMG，双击“安装 NERO 信披系统”。
2. 点击“安装并打开”，等待软件及完整资料恢复。
3. 此后双击桌面的“NERO 信披系统”图标，即可进入原有 Web UI。

软件默认安装在个人 Applications 目录。资料默认保存于：
~/Library/Application Support/NERO Disclosure

本包携带交付时的五类知识资料、会话、执行记录、附件和文稿版本。
知识库与个人数据保存在应用包外，可继续独立维护，不与原作者电脑同步。
本包不携带作者的 API Key、OAuth 登录令牌或宿主账号连接。首次使用请在模型设置中授权自己的账号；需要联网的模型及外部服务仍须可用。

完整迁移只恢复到新资料目录，不覆盖现有资料。若提示目录已存在，点击“选择数据目录”，选定一个父文件夹，安装器会在其中新建资料目录。已有应用须先退出，确认后才替换软件，并保留旧应用副本。

安装完成后可以推出 DMG；请在核对知识库、原会话和文件后再自行处理安装包。不要删除资料目录。安装失败时请查看安装器日志，不要手工覆盖数据库。
