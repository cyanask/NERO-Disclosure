NERO 信披系统 · Mac 安装说明

适用系统：macOS 13.5 或更新版本。Apple Silicon（M 系列）请选择 arm64 包，Intel 请选择 x86_64 包。

1. 打开 DMG，双击“NERO 信披系统.app”。
2. 点击“安装并打开”，程序安装到个人应用程序目录，公共知识库初始化到个人数据目录。
3. 工作台准备完成后自动在默认浏览器打开。首次使用请进入“模型设置”，授权自己的账号。

日常使用：在应用程序中打开“NERO 信披系统”。启动器可重新打开网页、查看资料位置和日志。退出启动器会停止本机服务。

数据保存位置：~/Library/Application Support/NERO Disclosure
02_knowledge 保存你可维护的知识库；03_local 保存事项、会话、交付物和本机配置。更新软件不会覆盖这两个目录。

迁移已有数据：先退出旧电脑上的服务，完整复制数据目录；在新电脑的安装界面，先点击“选择数据目录”，选中复制后的父目录，再安装并打开。模型账号须重新授权。

安装介质中的 02_knowledge 是公共知识库初始快照，PDF 原件在这个独立文件夹中，不嵌入 .app。安装完成后可以推出磁盘镜像。

本包不包含原作者的个人事项、会话、模型密钥或公司历史公告工作包。需使用公司历史时，可在工作台中自行导入。

更新软件：先退出当前启动器，再运行新 DMG 中的应用并确认更新。安装器不覆盖知识库和工作记录，并在应用目录保留旧应用回退副本。

分发状态：当前未完成 Apple Developer ID 签名与公证，其他 Mac 可能由系统安全策略阻止打开，暂不能保证一键放行。请参阅 Apple 官方安全打开应用说明：https://support.apple.com/zh-cn/102445 。不要关闭系统安全保护。
