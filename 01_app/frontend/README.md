# 信息披露界面

React / TypeScript / Vite / Ant Design。入口以公司为单位：用户填写公司全称和六位证券代码，Pi 联网查询并读取官方原文，核实所属板块后登记。已登记且选定的公司直接进入工作台；只有一家公司时自动恢复该公司。

`CompanyEntrance.tsx` 提供登记、查询进度、停止、失败重试和官方依据。`App.tsx` 管理当前公司及公司内导航，`companyWorkspace.ts` 提供公司范围的数据投影。交易所卡片、板块选择页、地标图片及手工指定板块的登记入口已移除。已保存的旧公司资料仍可使用。

法规、案例按适用板块组织；案例入口内区分普通案例与违规案例。模板包含板块通用版和公司专用版。本公司历史公告继续由“公告时间表”管理。会话、事项、执行记录与交付文件按公司筛选；系统治理查阅独立记录，不把其他范围的会话带入本公司工作。

NDT 路线为 `frontend-ui / ai-app-ui`。沿用现有黑金品牌与浅色工作区，新登记页采用两字段表单，保留真实进度、取消、错误和依据；没有新增依赖。当前仅开放创业板工作台。识别出尚未接入的板块会显示原因，不切换为其他板块继续办理。

公司工作台的验证记录、兼容性和上线边界保存在作者工作区的本机历史区，未随源码仓库分发；旧验收不代表当前修改已经完成验收。
