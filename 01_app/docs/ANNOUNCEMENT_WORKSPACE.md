# 历史公告与公告时间表

2026-09-14 当前页面：一级导航“公告时间表”统一管理本公司历史公告；知识库仅保留法规、案例、模板。公告记录、公司隔离和维护服务继续共用。标签分类和筛选见 [公告时间表标签](ANNOUNCEMENT_TAGS.md)。

历史公告要求发布日期和发布依据；生成并验收的未公开工作稿不自动进入历史公告。结构化字段保留原文定位，未知不补造。普通入库连续处理，歧义和删除、替换的影响集中确认。公告时间表核对与现有业务核验整合，确认仍绑定具体版本。

实施验收覆盖：公司隔离、上传格式及原件保真、页级抽取和 OCR 状态、重复入库、删除引用影响、手改模板保真及版本失效、会议届次/序号/日期冲突、同公司在制稿冲突、Pi 与页面同路径，以及前端实际操作。合成验证、真实材料抽查、模型调用与人工验收分别报告。

NDT：沿用当前 Ant Design 桌面工作台；primary_job 为查看与维护公告及其连续关系，assistance_mode 为工作台。状态使用现有等待、失败、完成和待核验标签，删除/替换显示对象及影响，正文与原件不被摘要替代。

已实现：

- 顶部选择或登记公司后，在一级菜单“公告时间表”检索、打开原件和校正字段或标签；更正、延期等可关联前序公告，同一会议自动建立关联。
- 新增入库支持批量 DOCX/PDF 上传或官方文件链接。Word 保留段落、表格及结构顺序，PDF 按页抽取并保留表格候选；低文本页和 Word 图片按需 OCR。PDF 页数不设固定上限；仍受文件大小、解密、格式和运行资源约束。原件保持不变，表格候选、OCR 和修订部分须核对，空缺不能伪装为完整抽取。
- 删除先预览确定对象及引用影响，再由后台修改当前记录和检索结果。历史公告可显示已删除条目并恢复；原件及必要历史引用保留。本地删除不等于市场公告撤回。
- 模板可下载手工修改后上传替换，也可沿用已有文种要求新增模板。公司专用模板按公司选择；后续生成按原模板填充，独立核对正文、表格、样式、页边距和页眉页脚。模板固定正文必须先纳入完整正文确认。
- Pi 增加本公司历史查询、上传文件页级读取、官方文件下载、导入清单、单份/批量入库预览及模板替换、删除预览能力。实际操作复用页面服务，模型不能代签发布或抽取确认。批次中断记录已完成文件，重试跳过这些文件。
- 业务核验检查本公司历史及其他在制稿的公告编号、会议届次/年度/序号及日期冲突。历史变化影响本公司的输入版本，其他公司不因这一变化失效。历史完整性声明有期间范围，不以“没有结果”证明没有历史。

使用：先在顶部登记本公司，再从公告时间表上传已发布公告或提交官方文件链接，核对标题、发布日期和发布依据。对话中的更新任务继续使用同一公司历史库。未公开工作稿仍留在交付文件中。

实现路径：`backend/announcement_history.py` 保存公司公告与结构化记录；`file_ingestion.py` 负责原件保真和抽取；`library_workspace.py` 复用既有版本写入及删除服务。未增加数据库或第二主控。macOS 使用系统 Vision，其他环境可使用已安装的 Tesseract；未配置引擎时明确返回待处理，不安装全局依赖。旧 `.doc` 需先另存为 `.docx`。
