# 1.0 完整试运行迁移版

交付物是一个压缩 DMG。原生安装窗口自动选择 Apple Silicon 或 Intel 软件组件，恢复同一份数据快照，并创建指向正式 `.app` 的桌面快捷方式。沿用现有 Web UI 和 A「披露之窗」图标，不依赖作者电脑的绝对路径。

## 数据范围

完整保留 `02_knowledge`，包含法规、普通案例、违规案例、模板、公司历史公告及其原件、正文、历史版本和 SQLite 索引。

本机业务资料随 `03_local` 迁移，包括事项数据库、会话数据库、`var/pi-runs` 中的上下文续接文件、文稿与附件各版本、归档记录和交付物。程序规则与运行环境随软件发布。旧业务记录不会因复制而变成接收者新执行或新确认的结果。

不复制开发缓存、旧虚拟环境、旧安装包、临时锁、进程身份、作者的账号连接及本机认证状态。排除项逐项记录在快照清单中，不删除源文件。非敏感模型设置保留；对方须授权自己的账号，可选外部通道仍须具备相应服务。

## 导出与保护

导出前须取得读取本系统历史资料和暂停服务的授权。先正常退出服务，确认没有运行中的任务，再执行 `scripts/migration_snapshot.py`。导出器获取工作区锁，只读备份 SQLite，并比较导出前后的源文件哈希；变化、损坏或疑似凭据会使快照不能分发。

凭据检查覆盖普通可读文件、数据库字段与可读压缩文件内容，不在报告中展示凭据值，不对业务原文静默删改。图像内的文字不自动 OCR 检查；命中项和不可检查的归档须单独处理。原库不因净化交付副本而改变。

复制结果先与源文件核对，再在副本中生成新的知识包清单。完整快照的 `MIGRATION_MANIFEST.json` 保存文件哈希、数据库表计数、来源哈希和排除项。

SQLite 交付副本会排除已退役的访问令牌摘要，并压实数据库以清除已删除页残留；保留所有可用业务记录和关联标识。清除的认证记录单独登记，原数据库不变。历史测试代码及工程批准说明的凭据误报，只有经复核且文件内容哈希完全一致时才允许通过。

## 安装与恢复

默认软件位置为 `~/Applications/NERO 信披系统.app`，默认资料位置为 `~/Library/Application Support/NERO Disclosure`。完整迁移只恢复到尚不存在的新资料目录；已有数据不合并、不覆盖。安装器允许选择父文件夹并在其中创建独立资料目录。

软件和资料分别复制到临时目录并校验，成功后才移到正式位置。替换旧应用须先由用户确认，旧应用保留回退副本。可恢复的安装异常和取消会回滚本次改动；断电等异常后保留的旧应用副本可用于人工恢复，不应自行覆盖数据库。

桌面图标是原生应用的 Finder 快捷方式，不是终端脚本。应用只停止由其自身启动的后台服务，重复打开使用同一资料目录时连接已有服务。普通软件升级不自动覆盖接收者的知识库和历史记录。

## 构建与验收

先分别用 `build_macos_release.py` 生成两个架构的 Release 软件，再用 `build_macos_migration.py` 合并为一个通用安装器和压缩 DMG。正式构建记录源码哈希、数据快照身份及安装包哈希。

验收须分别检查：空目录安装、安装失败保护、已有资料拒绝覆盖、桌面原生图标、知识库与历史记录计数、会话续接资料、旧附件和文稿、Word/Excel/PDF 能力、重复启动和退出重启。测试使用隔离副本；没有真实模型授权和调用的检查不得记作模型业务验收。

系统要求为 macOS 13.5 或更新版本。本机验证、Rosetta 验证和独立目标 Mac 验收分别记录，不相互替代。以当次发行目录中的实际验证回执为准。

当前没有 Developer ID 签名和公证，其他 Mac 可能拦截打开；不能承诺默认无提示放行，也不关闭系统安全保护。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。完整快照含业务资料和历史对话，只供获准接收者使用，不作公开发布。
