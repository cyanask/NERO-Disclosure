# 新用户教程

本教程带你完成首次启动、模型授权和一个事项的基本操作。先使用模拟事项熟悉流程，再在已明确授权的材料范围内处理实际工作。

## 1. 启动工作台

打开正式的 **NERO 信披系统 App**。本机现有入口位于桌面；安装到新 Mac 时，按[Mac 安装说明](../native/macos/INSTALL.txt)使用已提供的正式安装包。根目录原有双击脚本已退役。

App 启动本机服务并打开浏览器。启动器可重新打开网页、查看资料位置和日志；结束使用时退出启动器，网页关闭本身不会停止服务。模型账号须在工作台中自行授权。

本系统不要求另设用户名或密码。页面内的确认记录用于当前工作稿追溯，不证明使用者具有公司法定审批权限。Windows 发行与使用状态见 [Windows 说明](WINDOWS_FIRST_USE.md)，不能把 Mac App 当作 Windows 安装包。

## 2. 登记本公司

首次使用先从登记页右上角配置默认模型，再填写公司全称和六位证券代码，点击“联网核实并登记”。Pi 查询并读取官方来源，匹配公司身份和当前板块后登记并进入工作台。当前仅创业板已接入；识别到其他板块会保留依据并说明尚未接入。

已登记的公司会直接恢复工作台。需要选择其他已登记公司时，点击“公司设置”；当前公司的历史公告、会话和事项继续保留。

## 3. 配置一个可用模型

首次使用可从登记页右上角打开“模型设置”，进入工作台后也可从左侧打开。展开供应商后，可以看到模型、聊天栏显示、默认选择、连接状态和授权入口。

**使用 ChatGPT：** 展开 OpenAI / GPT，点击“登录 ChatGPT”，按弹窗提示到官方页面登录并输入设备码。完成后返回工作台，测试所选模型。

**使用 API Key：** 选择支持 API Key 的模型，将自己的密钥输入密码框并保存，再点击“测试连接”。密钥按供应商保存，同一供应商的所有模型共用，保存后系统会尝试读取该账号可用的云端模型，全部模型自动补入列表，缺省参数按 Pi 原生加载规则处理；也可在供应商下点“同步云端模型”重新拉取。多份不同旧密钥需要重新保存要共用的密钥；移除供应商授权会使该供应商全部模型失去共享授权。密钥进入系统凭据库，配置文件只保留模型和端点。不要把密钥发给 AI、写进教程或通过普通文件传递。

**使用 Gemini：** 这套配置与 NERO Banker 共用本机 OpenCodex Google 授权通道。先在当前电脑完成该通道的安装、授权与启动，再点击“检查已有授权”。只提供部分模型时，其他模型会显示不可用；不能用 `agy` 终端已登录来代替本通道的实际检查。新用户也可选择其他已授权供应商开始使用。

授权配置和连接测试是两步。连接测试发送固定短消息，可能消耗账号额度；它不验证法律或业务能力。通过后可设为默认模型，并勾选“聊天栏显示”。默认选择在下一轮生效，已经开始的执行不会中途换模型。

对话框中的模型选择属于当前会话，在同一浏览器内分别保存；切换会话或刷新后会恢复。尚无保存记录的旧会话按最近实际运行的模型显示，新会话使用配置默认值。更改一个会话的模型不会更改另一个会话，也不会改写历史执行记录。原模型不可用时，请手动重新选择。这里保存的只有模型标识，不包含密钥或对话正文。

换电脑或移动项目路径后，请重新授权并测试。历史上的“连接通过”记录只说明当时的环境。

## 4. 建立事项和会话

回到“对话操作台”即可在底部输入，首次发送时自动建立会话，无需先点“新建会话”。要另起一段对话时，点击会话列表旁的加号。可以直接咨询信披问题或查询知识库，无需先建立公司事项。准备办理具体事项时，说明事实、资料来源及是否需要 Word；公司名称、证券代码和所属板块沿用已登记信息，Pi 据此登记事项并选择处理流程。

执行期间可以继续起草下一条，结束后再发送。发送失败时保留输入，重试复用原请求编号；在当前页面内切换会话，各会话的草稿分别保留。草稿尚未提交，刷新或离开当前对话页面前请自行保存。Enter 发送，Shift + Enter 换行；中文输入法选字不会触发发送。

会话右侧可以归档。查看已归档会话时，每行都有恢复与删除按钮。删除前先核对对话中列出的专属记录、文件、备份及共享保留范围。

会话按首条问题命名，主控在同一轮需求判断时进一步概括；后续追问不替换首问标题，也不覆盖人工修改的名称。

## 5. 在会话中推进工作

直接说明需求即可。Pi 会结合当前资料处理信披咨询、公告起草、Word 制作或知识库查询与维护，无需手选任务类型。普通资料缺口可以标注待补后继续，影响判断的关键问题会单独提出。

顶部“工作进展”默认显示简短摘要。展开后查看本轮实际发生的工作，不预设需要走完的节点。咨询结束就可以结束，不要求继续制作公告；知识库变更预览、实际写入和用户确认分别显示。

需要文件时直接说“请制作成 Word”。系统按当前对象整理公告或咨询回复，保留文稿版本和待补事项。“文档”区可预览、下载及提出会话内修改要求；下载后的文件在系统外使用，无需回传。文件生成不表示已经审阅、定稿或发布。

| 当前提示 | 可采取的操作 |
| --- | --- |
| 正在处理 | 查看已发生的活动，或使用“停止执行”结束本轮 |
| 需要补充信息 | 通过“去补充”定位输入框，说明事实及来源 |
| 知识库变更待确认 | 查看现有变更预览，核对对象与范围后处理 |
| 正文或文件已保存 | 打开当前版本，核对待补内容并按需要继续修改 |
| 需要人工确认 | 进入对应审阅入口，核对指定版本及适用要求 |

已绑定事项提供“事项记录与审阅”和“查看确认记录”。旧事项继续保留原有门禁、确认及失效记录；查看进展不会代签确认，也不会因点击某个活动而触发重新核验。旧确认不自动转移到新版本。

暂停动效只改变显示，不停止任务。等待补充、确认、失败、取消、断线及历史状态均停止执行动效；连接中断时保留最后已知状态，恢复后重新同步，不自动重发原请求。

## 6. 补资料、停止和返工

缺少关键资料时，页面会列出本轮问题。直接在对话中说明补充事实或修订要求。Pi 区分事实补充与讨论问题，必要时仍可用事实表单核对。涉及关键事实的变化会使受影响的旧候选或确认失效；历史记录仍然保留。

执行过久或内容方向不对时，点击“停止执行”。已经发生的工具动作不会抹去，可从“执行记录”查看。本轮失败时，先核对授权、模型、网络或资料缺口，再手动重试；系统不会自动改用另一款模型。

确认后若页面显示自动接续正在排队，可点击“暂停自动接续”。页面会重新读取实际状态，已保存的正文确认保留；暂停请求不能撤销已经完成的工具动作。需要停止正在运行的模型时，使用“停止执行”。

检索不到资料时，可改用短关键词、条款编号或分组目录。本轮会复用同一资料版本的已读结果；连续三次搜索没有新增资料时，会提示读取已有条目、分组定位或明确缺口。部分匹配和空结果都不能说明法律上没有义务。

资料查询、读取和下载不设次数上限，空查提示不会阻止继续查询。单轮不设固定总时限；模型接口、输出大小、资源清理和“停止执行”仍然生效。

## 7. 查看结果

对话回复按正文长度自然延展，可连续滚动阅读。顶部提供“工作进展”“回到正文”“继续提问”。查看进展不压缩正文；“回到正文”恢复离开前的段落；“继续提问”返回当前会话并聚焦输入框。查看历史轮次时会明确标注范围，新请求不会发送到过去某轮。草稿保留，阅读位置在当前页面内记录。

“执行记录”按会话和轮次展示查阅依据；详细技术记录与事项办理记录在“系统治理”中保留。“交付文件”提供已经制作并登记的 Word；没有文件登记记录时，不把模型回复中的文件名当成交付完成。

模型结束但尚未登记可核验结果时，公开文字标为“未完成说明”。单轮没有固定五分钟上限，运行记录区分分流、业务模型、工具、收尾和资源清理耗时；用户可随时停止，未提交结果仍标记为未完成。分流使用独立低预算，正式分析和起草保留你选择的模型、档位。

运行记录分别保留模型正常结束和中断时的耗时，清理耗时包含回收子进程的等待。历史复测使用的计时口径可能不同，查看旧记录时以其说明为准；总耗时仍以总计字段为准。

Word 当前保留工作稿或模拟验收标识，自动格式检查不能替代逐页审阅。网页中的完成状态也不等于已经报送、公开发布或履行公司法定程序。

最新同题同资料复测已结束：DeepSeek 通过 A 进入 B，但 B 未完成；GPT 的 A 尚未通过。两者均达到十分钟上限，均未形成正文，也没有人工确认，不能视为完整业务成功。完整正文、Word 全流程和人工业务验收仍待完成，不据此承诺省 Token 或生产级效果。结果见最终验证记录（本机历史记录，未随源码仓库分发）。

## 常见问题

本公司历史公告从顶部公司选择开始。在一级页面“公告时间表”新增 DOCX/PDF 或官方文件链接，核对标题、发布日期和发布依据后入库。点击股东会、董事会、年报等标签即可筛选，再按通知、决议、法律意见书、全文或摘要细分；“更多标签”显示其他类别。搜索框与标签共同生效，点“全部”清除分类筛选，清空搜索词后再搜索可恢复完整列表。每行“校正”可调整标签并填写原因，也可恢复自动分类。只有已发布公告进入历史库，工作稿不会自动转入。

知识库通过“新增入库”和勾选后的“删除所选”维护资料。扫描页、图片表格或修订内容会提示核对；“交给 Pi 辅助核对”准备对话消息，发送后使用当前会话所选模型。自然语言更新支持同库多份文件集中确认，失败后保留已完成清单。模板详情可下载当前 Word，手工修改后上传替换；新版本不覆盖已交付文件。黑名单案例库按一项违规事项展示监管决定和关联文件，可按公告类型、错误类型、处理性质和年份筛选；历史处罚依据不能代替当前法规核对。

详见[历史公告与公告时间表](ANNOUNCEMENT_WORKSPACE.md)。

历史公告入库后，会对未达到99%经校准门槛的规则候选自动调用Pi复判。当前规则尚无该校准证据，候选均须复判；页面区分候选、Pi已复判和人工校正。Web上传使用已配置默认模型，对话入库使用原会话模型；模型未配置、服务离线或执行失败时保留待识别，可点击“Pi复判待识别”重试，并可暂停正在执行的复判。既有人工校正不会被Pi覆盖。

| 现象 | 先做什么 |
| --- | --- |
| 页面无法打开 | 查看启动窗口是否仍在运行，使用窗口显示的地址 |
| 提示端口被占用 | 先确认已有页面是否就是本项目；也可用 `--port 8878` 启动，不关闭未知进程 |
| 没有模型可选 | 在“模型设置”完成授权、启用模型并勾选聊天栏显示 |
| Gemini 不可用 | 检查当前电脑的 OpenCodex 服务、Google 授权和模型目录 |
| 新电脑显示需要授权 | 属于正常情况，系统凭据不会随文件夹迁移 |
| 模型完成了回复，但流程没前进 | 检查本轮是否仅为咨询、候选及自动核验是否完成、是否仍待人工确认 |
| Word 字体或分页不同 | 在当前电脑的 Word/WPS 中逐页检查；项目不安装商业字体或 Office |
| 首次下载失败 | 检查网络和公司代理策略后重试；不要关闭安全策略或删除业务数据 |

环境参数和整目录复制步骤见[迁移说明](MIGRATION.md)。
